# ☕ CoffeeFlow — Вебсистема онлайн-замовлень для кав’ярні

Практичний проєкт з дисципліни **«Технологічна практика»**  
**Спеціальність:** 122 «Комп’ютерні науки»  

## 🚀 Технологічний стек
- **Frontend:** React.js, Fetch API, HTML5/CSS3
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL + Prisma ORM
- **Architecture:** 3-tier Client-Server REST API

## 📁 Структура проєкту
- `/backend` — Серверна частина REST API та схема бази даних Prisma
- `/frontend` — React-інтерфейс замовлення для клієнта
